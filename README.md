# Мои смены

Приложение для телефона: график смен 3/3, замены и вызовы, документы со сроками действия.

Открывается в браузере и ставится на главный экран как обычное приложение (PWA).
Работает без интернета. Все данные — отметки, заметки, документы и фото — хранятся
только на телефоне и никуда не отправляются.

## Что умеет

- **График** — смены считаются сами от первого рабочего дня (22 октября 2026) по циклу
  3 через 3. На любой день можно отметить замену или вызов, отменённую смену,
  больничный или отпуск, поменять часы и оставить заметку.
- **Документы** — паспорт, СНИЛС, медкнижка, допуски и другие, с фото или PDF,
  номером и сроком действия. Заранее предупреждает, когда срок подходит к концу.
- **Итоги** — сколько смен, замен и часов за месяц и за год, примерная сумма по ставке.
  Табель можно отправить текстом или скачать таблицей для Excel.
- **Настройки** — цикл и время смены, ставка, добавление смен в календарь телефона
  (с напоминанием накануне), резервная копия и восстановление.

## Как поставить на телефон

- **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открыть в Chrome → меню ⋮ → «Установить приложение».

## Устройство

Обычные HTML, CSS и JS-модули без сборки: можно выложить на GitHub Pages как есть.
Данные лежат в IndexedDB, офлайн-работу обеспечивает `sw.js`.
После изменения файлов поменяй `VERSION` в `sw.js`, чтобы телефоны подтянули обновление.
